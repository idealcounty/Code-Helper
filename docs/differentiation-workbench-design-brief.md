# 差异化工作台设计简报

- **目的**：把 Code Helper 的算法验证、Agent 回放、上下文编译和记忆治理从后台能力变成可检查、可操作、可演示的产品界面。
- **主要用户**：需要验证算法正确性、调试 Agent 执行过程和治理上下文/记忆的开发者。
- **场景**：本地 Coding Agent 的专业分析工作台，不是营销页。
- **视觉方向**：银白色的 dense analyst workspace；青蓝表示可交互与正常运行，绿色表示确定性成功，琥珀表示估算或待确认，红色表示稳定失败证据。
- **记忆点**：所有结论都同时展示证据等级、来源和可追溯的 Session / Turn / Step。
- **约束**：保留原生 HTML/CSS/JavaScript、现有响应式布局和零新增依赖；不可伪造测试、正确性、Token 或记忆结论；核心安全上下文不可关闭。
- **交互原则**：工作台内的开关、分支、确认、归档和重新验证必须真实调用后端；历史回放不自动重放命令或文件写入。
- **响应式原则**：桌面保留表格、时间线和检查器的扫描效率；窄屏按工作流纵向排列，并保证主要按钮可点击、表格可横向滚动。
